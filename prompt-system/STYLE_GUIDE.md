# Style Guide

Create a premium illustration asset for a modern fintech mobile application. The goal is to build a consistent illustration library, not a standalone artwork. Every illustration must share the same visual language, construction principles, perspective, proportions, and color system. The output should look like it was designed by the same illustrator.

Illustration Style: Editorial vector illustration, Adobe Illustrator artwork, modern fintech illustration, professional mobile product icon, SVG-style artwork, flat illustration, subtle layered depth, paper-cut illustration — friendly, minimal, clean, simple, bold silhouette.

Rendering: Not a 3D render, not CGI, not Blender, not clay, not plastic, not photorealistic, not glossy, not toy-like. No realistic materials, no reflections, no ambient occlusion, no realistic shadows. Depth should be created only by layered vector faces.

Outline: No outline stroke of any kind — no thick outline, no thin outline, no hard black border. Edges are defined only by the boundary between adjacent flat color shapes.

# Form Language

Large geometric shapes, rounded geometry, chunky proportions, simple construction, minimal complexity, strong silhouette, large uninterrupted surfaces, high readability, friendly appearance. Avoid unnecessary details. Illustration first, realism second.
