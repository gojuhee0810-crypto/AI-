# Color Rules

Use one dominant color, one supporting color, one accent color. Primary 70%, Secondary 20%, Accent 10%. Flat colors only. No gradients. No glossy highlights. Neutral gray only for supporting elements. Colors must be highly saturated and vivid — never muted, dusty, or pastel.

# Object Color Map

Main Body → Primary. Functional Parts (handles, straps, covers, secondary surfaces) → Secondary. Accent Parts (coins, chips, badges, tags, buttons) → Accent. Neutral Parts (text lines, paper, wheels, outlines) → Gray/White.
