# Object Blueprint: Travel Suitcase

## OBJECT
Travel Suitcase

## CATEGORY
Travel (Primary Blue · Secondary Yellow · Accent Orange)

## PURPOSE
Represents travel luggage. Must remain recognizable at 32px.

## CONSTRUCTION
Large suitcase body. Retractable handle. Four small round spinner wheels, all the same size, evenly spaced in a single row along the bottom edge of the body — not three, not clustered, not overlapping. Small luggage tag.

## SILHOUETTE
Tall rounded rectangle. Rounded corners. Large body.

## PROPORTION
Body 70%. Handle 15%. Wheels 10%. Tag 5%.

## RECOGNITION CUE
Modern travel suitcase with a large telescopic handle and four wheels.

## OPTIONAL DETAILS
Vertical grooves. Minimal zipper line.
