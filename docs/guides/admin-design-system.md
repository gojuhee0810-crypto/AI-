# 광고센터 어드민 디자인 시스템

> 광고주가 캠페인·광고그룹·소재(배너)를 생성하고 심사 요청하는 카카오페이 광고센터 어드민 화면의 디자인 기준입니다.
> 아래는 실제 어드민 화면 스크린샷(캠페인 만들기 / 광고그룹 만들기 / 소재 만들기)을 보고 정리한 내용입니다.
> 정확한 컬러 hex, 폰트, spacing 토큰은 Figma MCP 연동 후 추출값으로 교체 예정이며, 그 전까지는 스크린샷 기반 추정치입니다.

## 1. 전체 플로우 (3단계)

```
1. 캠페인 만들기
   광고 상품(Fit 배너 / Full Screen 배너) 선택 → 캠페인 이름, 카테고리 지정
        ↓ "등록하고 광고그룹 만들기"
2. 광고그룹 만들기
   타겟팅, 집행 기간/시간, 예산(그룹 예산 / 일 예산) 설정
        ↓ "등록하고 소재 만들기"
3. 소재 만들기
   카피(메인/서브/안내문구), 이미지, 랜딩URL, 심사 참고사항 입력 → 미리보기 확인
        ↓ "등록하고 심사 요청하기"
```

우리 서비스(`adcenter-register` 스킬)는 이 3단계 중 **3단계 "소재 만들기"** 폼을 API/자동화로 채우는 것이 핵심 타깃입니다. 1~2단계(캠페인/광고그룹)는 광고주가 이미 만들어둔 것을 전제로 하거나, 추후 자동화 범위를 논의합니다.

## 2. 화면별 필드 정의

### 2-1. 캠페인 만들기
| 필드 | 타입 | 필수 | 제약 |
|---|---|---|---|
| 광고 상품 | 라디오 (Fit 배너 / Full Screen 배너) | ✓ | 우측에 상품별 미리보기 표시 |
| 캠페인 이름 | 텍스트 | ✓ | 25자 |
| 카테고리 | 2단계 depth 드롭다운 | ✓ | 대분류(교육/교통/금융/레저스포츠/반려동물/뷰티미용/생활서비스/쇼핑/온라인쇼핑/숙박/여행 등) → 소분류 |

### 2-2. 광고그룹 만들기
| 필드 | 타입 | 필수 | 제약 |
|---|---|---|---|
| 광고그룹 이름 | 텍스트 | ✓ | 25자 |
| 타겟팅 | 체크형 선택 (맞춤타겟 / 데모그래픽, 둘 중 하나만) | - | 맞춤타겟은 "카카오페이 광고 담당자로부터 전달받은 맞춤타겟 번호" 입력 방식 (툴팁 안내) |
| 집행 기간 | 날짜 범위 (시작일 - 종료일) | ✓ | 캘린더 피커 |
| 집행 시간 | 라디오 (모든 시간 / 요일별 시간대 설정) | ✓ | |
| 광고그룹 예산 (VAT 제외) | 숫자 입력 + 원 단위 표시 | ✓ | 캠페인 잔여 예산 이하 |
| 일 예산 (VAT 제외) | 숫자 입력 | ✓ | 광고그룹 예산 이하 |

### 2-3. 소재 만들기 (Fit 배너 기준)
| 필드 | 타입 | 필수 | 제약 |
|---|---|---|---|
| 소재 이름 | 텍스트 | ✓ | 25자 |
| 메인 카피 | 텍스트 | ✓ | **14자** (공백 포함) |
| 서브 카피 | 텍스트 | - | **15자** (공백 포함) |
| 안내 문구 | 텍스트 | - | 60자 (심의필 등 법적 고지용) |
| 이미지 | 파일 업로드 | ✓ | PNG, 500KB 이하, **240×240px** |
| 랜딩URL | URL 텍스트 | ✓ | `https://` 형식 |
| 심사 참고사항 | 텍스트영역 | - | 500자 |

> ⚠️ 이 글자수/이미지 스펙은 `image-style-patterns.md`, `copy-patterns.md`, `kakaopay-banner-guide.md`에도 반영해야 합니다 — 메인 카피 14자는 매우 타이트하므로 카피 생성 스킬의 프롬프트 제약을 이 값으로 맞춰야 합니다. (반영 완료: kakaopay-banner-guide.md)

**Full Screen 배너 소재 폼**은 이번 스크린샷에 포함되지 않음 — TBD. 다만 미리보기상 구성은 헤드라인(예: "3% 돌려드려요!") + 서브카피(혜택 요약) + 기간 정보 + CTA 버튼("혜택 확인하기") 구조로 추정됩니다.

## 3. 컬러

**hex 값은 여기 적지 않는다.** `src/app/globals.css`가 유일한 진실이고, 문서에 옮겨
적으면 반드시 어긋난다 — 실제로 2026-08-08 이전 이 문서엔 "헤더·사이드바 = 거의 블랙",
"옐로우 #FEE500 부근"이라는 추정치가 있었고, 그걸 믿고 구현했다가 전부 다시 만들었다.
(Figma 실측: 사이드바는 밝은 회색, 옐로우는 `#FFEB00`)

아래는 **어디에 무슨 토큰을 쓰는지**만 적는다. 값은 CSS에서 확인할 것.

| 토큰 | 쓰는 곳 |
|---|---|
| `--color-header` | 최상단 GNB (다크) |
| `--color-sidebar` | 좌측 LNB, 우측 미리보기 패널 |
| `--color-page` / `--color-surface` | 본문 배경 / 카드·인풋 |
| `--color-brand` | Primary CTA, 선택된 라디오 |
| `--color-ink` / `--color-ink-muted` / `--color-ink-faint` | 본문 / 보조 / placeholder |
| `--color-line` | 구분선, 인풋 테두리 |
| `--color-fill` / `--color-fill-strong` | 보조 버튼 / reverse 버튼 |
| `--color-required` | 필수 `*` |
| `--color-accent` / `--color-accent-soft` | 배지 텍스트 / 배지 배경 |

## 6. 컴포넌트 스펙

### 6-1. 버튼

모두 **pill 형태(radius 24px)** 다. 사각 버튼은 쓰지 않는다.

| 종류 | 높이 | 배경 / 테두리 | 텍스트 | 쓰는 곳 |
|---|---|---|---|---|
| **Primary** | 48 | `--color-brand` | 16/26 Medium, ink | 하단 주요 CTA, 진행 가능한 생성 버튼 |
| **Support** | 48 | `--color-fill` | 16/26 Medium, ink | 취소, 비활성 상태의 생성 버튼 |
| **Outline** | 48~54 | white + `--color-line` | 16/26 SemiBold, ink | "AI 카피 다시 추천 받기" |
| **Outline (dark bg)** | 36 | 투명 + white 1px | 14/22 Medium, white | GNB 로그아웃 |
| **Reverse** | 36 | `--color-fill-strong` | 14/22 Medium, white | 로고 업로드 |
| **Chip** | 32 | white + `--color-line` | 13/20 Medium, ink-muted | 카드 내 "수정", "다시 생성하기" |

**옐로우는 화면에 하나만.** 지금 눌러야 진행되는 버튼에만 Primary를 쓰고, 결과가 나와
주요 액션이 다음 단계로 넘어가면 그 버튼은 Support로 내린다.

**하단 글로벌 버튼에는 아이콘을 넣지 않는다.** 아이콘은 인라인 액션(수정, 다시 생성,
업로드, AI 생성)에만 허용한다.

### 6-2. 입력

| 항목 | 값 |
|---|---|
| 높이 | 48 (단일행) / 139 (여러 줄) |
| 모서리 | radius 8 (버튼과 달리 pill 아님) |
| 테두리 | `--color-line`, 포커스 시 `--color-ink` |
| 안쪽 여백 | 좌우 16 |
| placeholder | `--color-ink-faint` |
| 글자수 카운터 | 우측 정렬, Caption, 좌우 16 패딩, `tabular-nums` 필수 |

### 6-3. 라디오

- 원 24px. **선택 시 `--color-brand`로 채운다** (테두리만 바뀌는 방식 아님)
- 카드형(이미지 유형)은 높이 48, radius 8, 선택 시 테두리 `--color-ink`

### 6-4. 그 외

- **배지**: radius 999, `--color-accent-soft` 배경 + `--color-accent` 텍스트, 14/22
- **툴팁**: 검정 말풍선, radius 8, 14/22 white. ⓘ 아이콘에 hover/focus 시 노출
- **목록 안내문**: 점(·) 불릿 + Body small, `--color-ink-muted`
