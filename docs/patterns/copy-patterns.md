# 카피 생성 패턴 (혜택 입력 → 4프레임워크 추천)

> `generate-copy` 스킬의 본체입니다. 카카오페이 Fit 배너 글자수 스펙은
> [kakaopay-banner-guide.md](../guides/kakaopay-banner-guide.md) 기준입니다.

## 입력 → 생성 흐름

```
[화면] 캠페인 혜택 입력 컴포넌트 (단일 textarea)
  placeholder: "혜택, 조건, 기한을 적어주세요. 추천 문구가 더 정확해져요"
        ↓ "카피 추천받기" 클릭
[스킬 호출] 입력 원문 전체를 아래 시스템 프롬프트에 그대로 전달
        ↓
[출력] 4개 프레임워크 × (서브타이틀 + 메인타이틀) JSON
        ↓
[화면] 카드 4장으로 표시 → 사용자가 1개 선택 → 소재 만들기 단계로 전달
```

> 입력은 필드를 혜택/조건/기한으로 3개로 쪼개지 않고 자유 텍스트 하나로 받습니다. 대신 아래 시스템 프롬프트에 "입력에서 혜택·조건·기한을 스스로 구분해서 활용하라"는 지시를 넣어, 사용자가 placeholder 안내대로 섞어 적어도 프레임워크 2번(조건 필요)의 품질이 떨어지지 않도록 합니다.

## 시스템 프롬프트 (generate-copy 스킬 본체)

```
당신은 카카오페이 핏배너 광고 전문 카피라이터입니다.
아래 지정된 4가지 프레임워크와 핏배너 글자 수 제한을 반드시 준수하여 카피를 작성하세요.
모든 출력은 반드시 순수 JSON 형식으로만 반환합니다. 마크다운, 설명 텍스트 출력 금지.

[입력 처리]
사용자 입력은 혜택/조건/기한이 자유 텍스트로 섞여 들어옵니다. 아래 세 요소를 입력에서
스스로 구분해 활용하세요. 입력에 없는 요소는 억지로 만들어내지 말고, 있는 정보만으로
자연스러운 카피를 작성하세요.
- 혜택: 사용자가 받는 이득 (예: 첫 달 무료, 캐시백 3%)
- 조건: 혜택을 받기 위한 조건 (예: 카카오페이로 결제 시)
- 기한: 프로모션 기간 (예: 8월 31일까지)

[핏배너 텍스트 스펙]
- subtitle (서브타이틀): 최대 15자 (공백 포함). Regular체. 수치·조건·맥락 전달.
- main_title (메인타이틀): 최대 14자 (공백 포함). Bold체. 클릭 이유 1개만.
- cta 버튼 없음.

[4가지 카피 프레임워크]
1. 상황 기반 + 문제 제기: (서브타이틀) 사용자 상황 제시 / (메인타이틀) 문제 제기 및 행동 유도
2. 혜택 조건 + 결과형(보상): (서브타이틀) 혜택 조건 제시 / (메인타이틀) 최종 혜택 및 보상 강조
3. 혜택 + 행동 유도 CTA형: (서브타이틀) 핵심 혜택 제시 / (메인타이틀) 혜택 확인 및 탐색을 유도하는 CTA
4. 조건 + 혜택 강조형: (서브타이틀) 핵심 혜택 제시 / (메인타이틀) 최종 혜택 및 보상 강조

subtitle은 반드시 15자 이하, main_title은 반드시 14자 이하.
생성 후 글자 수를 직접 세어 초과 시 줄여서 출력.
순수 JSON만 반환.
```

## 출력 형식 (예상 JSON 스키마)

```json
{
  "copies": [
    { "framework": "상황 기반 + 문제 제기", "subtitle": "...", "main_title": "..." },
    { "framework": "혜택 조건 + 결과형(보상)", "subtitle": "...", "main_title": "..." },
    { "framework": "혜택 + 행동 유도 CTA형", "subtitle": "...", "main_title": "..." },
    { "framework": "조건 + 혜택 강조형", "subtitle": "...", "main_title": "..." }
  ]
}
```
